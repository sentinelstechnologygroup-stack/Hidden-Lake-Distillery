# Hidden Lake Distillery

Standalone Vite/React storefront with an Express/Better Auth/PostgreSQL API.
Read README.md and docs/DEPLOYMENT.md before changes. Run npm run check.
Never add hosted-builder SDKs, browser secrets, raw payment card storage, or live alcohol checkout without configured providers and fulfillment rules.
Keep owner-scoped queries and admin checks on the server. Migration SQL is versioned.
